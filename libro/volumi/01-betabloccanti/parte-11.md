| Condizione | Ruolo | Note |
|---|---|---|

| Angina cronica | Prima linea (con calcio-antagonisti) | Obiettivo FC 55–60 bpm |
| Post-infarto con FE ridotta | Indicato | Dose target/tollerata |
| Post-infarto con FE conservata | Individualizzare | REDUCE-AMI, REBOOT, ABYSS |

| QT lungo, CPVT | Prima linea | Nadololo, propranololo |
| Dissezione aortica | Prima misura | Esmololo, labetalolo |

### Soglie di sicurezza indicative

| Segno | Soglia didattica | Azione |
|---|---|---|
| Frequenza cardiaca | < 50–60 bpm o sintomatica | Non somministrare, avvisare |
| Pressione sistolica | < 90–100 mmHg o sintomatica | Non somministrare, avvisare |
| PR all'ECG | Allungamento o nuovo blocco AV | Avvisare il medico |
| Glicemia (diabetici) | Ipoglicemia | Trattare, rivalutare terapia |
| Peso | + 2 kg in 3 giorni | Avvisare |

### Mini-algoritmo di scelta (didattico)

| Domanda | Se sì | Se no |
|---|---|---|
| Shock, bradicardia grave, blocco AV non protetto, broncospasmo attivo? | Non somministrare; avvisare | Prosegui |
| Scompenso acuto con congestione o ipoperfusione? | Non avviare; se già in terapia, valutare riduzione | Prosegui |
| HFrEF stabile? | Bisoprololo, carvedilolo, metoprololo succinato, nebivololo | Prosegui |
| Angina o aritmia che richiede controllo? | β1-selettivo; evitare verapamil/diltiazem in associazione | Valutare altre classi |
| Ipertensione senza altre indicazioni? | Non è prima linea | Prima linea: ACE-i/sartano, CCB, tiazidico |
| Gravidanza? | Labetalolo o metoprololo | Scelta ordinaria |

## Checklist operative

### Prima di somministrare

- [ ] Prescrizione chiara: farmaco, dose, via, orario, indicazione.
- [ ] Identificazione del paziente verificata.
- [ ] Polso (60 s) e pressione registrati; confronto con le soglie.
- [ ] Nessun sibilo nuovo, dispnea o sincope.
- [ ] Controllo di terapie interferenti (calcio-antagonisti, digossina, amiodarone, clonidina).
- [ ] Formulazione corretta; compresse a rilascio prolungato non frantumate.
- [ ] Per EV: diluizione, velocità, linea dedicata, monitor ECG.

### Durante e dopo la somministrazione

- [ ] Paziente supino per EV (soprattutto labetalolo).
- [ ] Monitoraggio continuo e parametri ai tempi stabiliti.
- [ ] Documentazione di parametri, effetti e comunicazioni al medico.
- [ ] Segnalazione di eventi avversi.

### Dimissione e educazione

- [ ] Il paziente sa nome, scopo e orari del farmaco.
- [ ] Spiegato di non sospendere bruscamente.
- [ ] Insegnata la misurazione del polso e della pressione.
- [ ] Consegnato l'elenco dei farmaci e dei segni di allarme.
- [ ] Caregiver coinvolto; follow-up programmato.

### Emergenza: sospetta intossicazione

- [ ] Vie aeree, ossigeno, accesso venoso, monitor.
- [ ] Glicemia e elettroliti.
- [ ] Contatto con Centro Antiveleni.
- [ ] Preparazione di atropina, glucagone, calcio, vasopressori, stimolazione.
- [ ] Documentazione di farmaco, dose, orario, formulazione.

## Glossario

| Termine | Definizione |
|---|---|
| Adenilato ciclasi | Enzima che converte ATP in cAMP, attivato dalla proteina Gs |
| ACE-inibitore / ARNI | Inibitore dell'enzima di conversione / associazione sacubitril-valsartan |
| Agonista parziale | Sostanza che attiva solo in parte il recettore (base dell'ISA) |
| BPCO | Broncopneumopatia cronica ostruttiva |
| cAMP | Adenosin monofosfato ciclico, secondo messaggero intracellulare |
| Cardioselettività | Maggiore affinità per i recettori β1 rispetto ai β2 |
| Cronotropismo, inotropismo, dromotropismo, lusitropismo | Effetti su frequenza, contrattilità, conduzione e rilassamento |
| CYP2D6 | Isoenzima epatico con polimorfismo genetico, metabolizza molti betabloccanti |
| Downregulation / upregulation | Riduzione / aumento del numero di recettori |
| FE | Frazione di eiezione ventricolare sinistra |
| HFrEF | Scompenso con frazione di eiezione ridotta (≤ 40%) |
| HIET | Terapia con insulina ad alte dosi e euglicemia |
| ISA | Attività simpaticomimetica intrinseca |
| Lipofilia | Affinità per i lipidi; determina la penetrazione nel sistema nervoso centrale |
| MAO / COMT | Enzimi che degradano le catecolamine |
| NET | Trasportatore della noradrenalina per la ricaptazione |
| NYHA | Classificazione funzionale dello scompenso (I–IV) |
| PNMT | Enzima che converte noradrenalina in adrenalina |
| QTc | Intervallo QT corretto per la frequenza |
| Rebound | Peggioramento clinico alla sospensione brusca |
| RCP | Riassunto delle Caratteristiche del Prodotto |
| SNA | Sistema nervoso autonomo |
| STEMI | Infarto con sopraslivellamento del tratto ST |
| Torsione di punta | Tachicardia ventricolare polimorfa associata a QT lungo |
| Titolazione | Aggiustamento graduale della dose fino al target o alla dose tollerata |

## Fonti e dichiarazione finale

Questo volume cita per nome e anno le principali linee guida e gli studi di riferimento. L'elenco è selettivo, non esaustivo, ed è stato compilato **senza includere riferimenti non verificabili**. I dettagli bibliografici completi (volume, pagine, DOI) vanno recuperati sulle fonti originali, ad esempio PubMed e il sito ESC, prima di ogni citazione formale o uso in un lavoro scritto.

### Fonti per i farmaci in Italia

Riassunto delle Caratteristiche del Prodotto (RCP) dei singoli medicinali, nella Banca Dati Farmaci dell'AIFA; Rete Nazionale di Farmacovigilanza AIFA per le segnalazioni.

!!! nota "Nota – Stato delle evidenze"
    Il volume è ancorato alle linee guida ESC 2023/2024. Gli studi pubblicati nel 2025 (ad esempio REBOOT) e le nuove linee guida successive possono modificare alcune raccomandazioni: la verifica delle versioni correnti è parte integrante dell'uso del manuale.
